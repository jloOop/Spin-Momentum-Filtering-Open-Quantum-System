# Task-08X omega-dependence verification and analysis package

This package contains an independent, read-only verification and scientific analysis of the supplied Task-08X extended upward-response confinement aggregate.

## Contents

- `reports/`: the 33-page detailed report and the 51-page 50-figure atlas, in PDF and DOCX.
- `figures/`: all 50 high-resolution analysis figures.
- `tables/`: independently reconstructed and derived CSV/JSON tables.
- `reproduced_task08_aggregate/`: a clean local reproduction of the supplied Task-08X aggregate outputs, generated by the supplied read-only loader. The redundant nested share ZIP is omitted.
- `analysis_code/`: scripts used to verify, derive, plot, and author the reports.
- `verification_logs/`: local preflight and independent-rebuild logs.
- `Task08X_Figure_Index.md`: figure-by-figure index and scientific captions.
- `MANIFEST_SHA256.txt`: SHA-256 checksums of every file in this package other than the manifest itself.

## Verification scope

The archive and 18-case matrix pass CRC, SHA-256, manifest, identity, causal-kernel, tangent-closure, source-trace, jump-plus-anticommutator, and independent-reconstruction checks. The scientific status remains a descriptive zero-rate extended-family result. Finite-positive-rate, finite-temperature, universal-scaling, and publication-level cross-omega convergence claims are not authorized by this package. All 18 same-prefix deterministic reruns remain pending as a reproducibility qualification.
